# Contributing

Thanks for helping. The most useful contributions:

- A screen or setting name changed on GitHub and a guide is out of date.
- A script fails on your setup (include `gh --version` and the output with `DRY_RUN=1`).
- A missing example organization layout.

Keep pull requests to one change. Run `bash -n scripts/*.sh` and, if installed, `shellcheck scripts/*.sh` before opening one. Sign off commits with `git commit -s`.

Do not add promotional text to the guides. They should help a developer finish the task.
