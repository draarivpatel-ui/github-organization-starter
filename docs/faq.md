# FAQ

**Is a GitHub organization free?** Yes. The Free plan includes unlimited public and private repositories and unlimited collaborators; some features need a paid plan.

**Can I create an organization with the GitHub CLI or API?** Not on github.com. Creation is a web UI step. Enterprise Cloud admins have separate APIs.

**What is the difference between a user account and an organization?** An organization has no password or login of its own. People sign in with their personal accounts and act through roles and teams.

**Can I convert my personal account to an organization?** Yes, in your account settings under Organizations, **Turn into an organization**. Read GitHub's warnings first; it cannot be undone.

**How many owners should I have?** Two or three.

**How do I show a README on the organization page?** Add `profile/README.md` to a public repository named `.github`.

**Can I rename an organization?** Yes, under Settings. Old URLs redirect for a while, but update clone URLs and badges.

**How do I move an existing repository into the organization?** Repository Settings, Danger Zone, **Transfer ownership**.

**How do I delete an organization?** Settings, Danger Zone. Transfer or archive repositories you want to keep first.
