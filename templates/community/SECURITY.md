# Security Policy

## Reporting a vulnerability

Please do not open a public issue. Use **Security, Report a vulnerability** on the affected repository (private vulnerability reporting), or email **security@YOUR_DOMAIN**.

Include what you found, steps to reproduce and the affected version. We aim to acknowledge reports within 3 working days and to share a fix timeline within 10.

## Supported versions

The latest release of each project receives security fixes unless its README says otherwise.
